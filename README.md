# 電力運用シミュレータ (Electric Power Company Simulator)

Pyxel（レトロゲームエンジン）で開発された2D電力需給・周波数制御シミュレーションゲームです。
プレイヤーは中央給電指令所となり、町の送配電網を俯瞰しながら発電所出力と送電をコントロールし、**定格周波数 60.00 Hz** を維持しつつハイスコア（累計売電収入）を目指します。

---

## 1. 起動方法

### Python スクリプトとして起動する場合
Anaconda環境 `GameEmv` を有効化し、`main.py` を実行します。

```bash
conda activate GameEmv
python main.py
```

### Windows exe アプリケーションとして起動する場合
ビルド成果物 `dist/PowerGridSim/PowerGridSim.exe` をダブルクリックして起動できます。（Python環境のないPCでも動作します）

---

## 2. exe 化（ビルド）の手順

本プロジェクトには、PyInstallerを用いたワンクリックexe化の仕組みが組み込まれています。

### 方法A: バッチファイルからビルド（推奨）
プロジェクト直下の **`build_exe.bat`** をダブルクリックして実行します。

### 方法B: コマンドラインからビルド
```bash
conda activate GameEmv
python build_exe.py
```

ビルドが完了すると、**`dist/PowerGridSim/`** フォルダ内に以下が生成されます：
- `PowerGridSim.exe` : ゲーム本体
- `config.json` : 難易度や設備データ（ユーザーがメモ帳等で自由に編集可能）
- `scenario.json` : イベントシナリオ（ユーザーが自由に編集可能）
- `assets/` : フォント等のアセット
- `README.md` : 説明書

> **配布方法**: `dist/PowerGridSim` フォルダごとZIP等に圧縮して配布すれば、相手のPCにPythonやPyxelがインストールされていなくてもそのまま遊んでもらえます。

## 3. ゲームルール & システム概要

### 🎯 主な目標
1. **周波数を 60.00 Hz に保つ**：
   - **供給（発電） > 需要** のとき、周波数が **上昇** します。
   - **供給（発電） < 需要** のとき、周波数が **低下** します。
   - 許容範囲（例: 60.00 ± 0.50 Hz）を一定時間（例: 5秒間）以上逸脱し続けると、**系統崩壊（BLACKOUT）** が発生しゲームオーバーとなります。
   - 危険域に入ると、画面の警報ランプ・メーターが赤く点滅し、ピピピッと警告音が鳴り響きます。
2. **電力を販売してスコア（累計売電額）と資金を獲得する**：
   - 需要家（民家・工場）に送電している間、`供給電力量 × 単価` で売電収入が入ります。
   - 基準単価は **30円/kWh** ですが、市場イベントによって係数が変動します。
3. **獲得した資金で発電所を増設する**：
   - 街は時間経過とともに発展し、新しい住宅街や工場が自動接続されて負荷が増えていきます。
   - 蓄えた資金で火力・水力・揚水発電所を増設して増大する需要に応えましょう。

## 3. 発電所 & 設備一覧

| 設備種別 | 特徴 | プレイヤーの操作 |
| :--- | :--- | :--- |
| **火力発電所** | 出力を広範囲に調整可能。ただし追従速度（ランプ速度）のタイムラグがある。 | `[-10]`, `[-1]`, `[+1]`, `[+10]`, `[MIN]`, `[MAX]` ボタン または `W` / `S` キー / `↑` / `↓` キー |
| **流れ込み式水力発電所** | 河川の流量に応じて安定発電するクリーンなベースロード。豊水イベントで発電量がUP。 | ベースロード（安定自動出力） |
| **揚水発電所** | 上部ダムに水を貯めておく蓄電プラント。**高効率・超高速応答**。 | `[OFF]`, `[発電(GEN)]`, `[揚水(PUMP)]` ボタン または `Space` キー |

### 💡 揚水発電を使ったハイスコア戦略
- **単価係数 < 1.0 のとき（電力余剰・休日・豊水など）**:
  - 需要が減って周波数が上昇傾向になります。
  - ここで揚水発電所を **`揚水 (PUMP)`** に切り替えます！
  - 系統から大電力を消費して周波数の急上昇を抑えつつ、安値の電気で上部ダムを満タンにチャージできます。
- **単価係数 > 1.0 のとき（電力不足・夕暮れ・寒波など）**:
  - 需要が跳ね上がり周波数が低下傾向になります。
  - ここで揚水発電所を **`発電 (GEN)`** に切り替えます！
  - 一気に大電力を供給して周波数低下を防ぎつつ、高騰したプレミア単価で大量売電して莫大な収益を獲得できます。

## 4. 需要家と送電スイッチ

- **中央区住宅街 / 東町ニュータウン / 新興住宅街**: 民家地区。生活リズムや天候・気温によりエアコン等の需要が変動します。
- **西部工業コンビナート / ハイテク工場**: 工場地区。大電力を消費します。
- **送電切替スイッチ (`[送電 切替(ON/OFF)]`)**:
  - プレイヤーは需要家の消費負荷自体を直接操作することはできませんが、送電を一時的に**遮断（意図的停電）**することができます。
  - 周波数が危険レベルまで急落した際の緊急負荷遮断手段として活用できます（ただし遮断中は売電収入が得られません）。

## 5. UIと監視機能

- **上部 HUD**:
  - 経過時間、所持資金、累計売電スコア、現在単価（基準30円 × 係数）、需給サマリー（供給MW / 需要MW / 需給差）。
  - **グラフィカル周波数メーター**: 許容安全ゾーン（緑帯）、中央60Hzライン、現在の指針、警報ランプ、危険継続時間カウントダウンバー。
- **中央マップ**:
  - 送電網のトポロジーと各発電所・需要家の稼働状態。
  - **潮流アニメーション**: 電線に流れる電力（MW）の向きと速さに応じたパルス粒子が流れます。過負荷に近づくと電線の色が橙〜赤に変化します。
  - **潮流ツールチップ**: マウスカーソルを電線の上に合わせると、`潮流: XX.X MW / 容量: XX MW` をリアルタイム監視できます。
- **下部コントロールパネル**:
  - 選択中のオブジェクトの詳細ステータス・操作ボタン。
  - 設備新設ボタン（火力増設 / 水力増設 / 揚水増設）。

## 6. シナリオ・設定のカスタマイズ（外部モデル化）

イベントや難易度は JSON ファイルで簡単に編集・追加できます。

### `config.json`
難易度別の周波数許容範囲や猶予時間、発電設備のパラメータを設定できます。
```json
"difficulties": {
  "easy": {
    "name": "初級 (Easy)",
    "freq_tolerance_hz": 0.8,
    "max_violation_duration_sec": 8.0,
    "initial_money_bonus": 50000
  },
  "normal": {
    "name": "中級 (Normal)",
    "freq_tolerance_hz": 0.5,
    "max_violation_duration_sec": 5.0,
    "initial_money_bonus": 0
  },
  "hard": {
    "name": "上級 (Hard)",
    "freq_tolerance_hz": 0.3,
    "max_violation_duration_sec": 3.0,
    "initial_money_bonus": -30000
  }
}
```

### `scenario.json`
時間経過で発生するイベント、事前予告の秒数、予告メッセージ、単価や負荷の倍率を設定できます。
```json
{
  "trigger_time_sec": 180,
  "notice_time_sec": 15,
  "duration_sec": 45,
  "name": "突発的寒波の襲来",
  "notice_msg": "【予告】急激な寒波が接近中！暖房需要爆発で電力ひっ迫、単価が超高騰する見込みです！",
  "active_msg": "【イベント発生】大寒波襲来！電力不足警報発令中！揚水発電を全開にして高値売電を狙え！",
  "price_multiplier": 2.2,
  "load_multiplier": 1.6,
  "hydro_multiplier": 0.8
}
```
新しいイベントを追加したい場合は、上記のオブジェクトを配列内に追加するだけで即座にゲーム内に反映されます。
