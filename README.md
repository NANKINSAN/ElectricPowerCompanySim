# 電力運用シミュレータ (Electric Power Company Simulator)

Pyxel（レトロゲームエンジン）で開発された2D電力需給・周波数制御シミュレーションゲームです。
プレイヤーは中央給電指令所となり、町の送配電網を俯瞰しながら発電所出力と送電をコントロールし、**定格周波数 60.00 Hz** を維持しつつハイスコア（累計売電収入）を目指します。

---

## 1. 起動方法

### Python スクリプトとして起動する場合
Anaconda環境 `GameEmv` を有効化し、`main.py` を実行します。

```bash
conda activate GameEmv
python main.py
```

### Windows exe アプリケーションとして起動する場合
ビルド成果物 `dist/PowerGridSim/PowerGridSim.exe` をダブルクリックして起動できます。（Python環境のないPCでも動作します）

---

## 2. exe 化（ビルド）の手順

本プロジェクトには、PyInstallerを用いたワンクリックexe化の仕組みが組み込まれています。

### 方法A: バッチファイルからビルド（推奨）
プロジェクト直下の **`build_exe.bat`** をダブルクリックして実行します。

### 方法B: コマンドラインからビルド
```bash
conda activate GameEmv
python build_exe.py
```

ビルドが完了すると、**`dist/PowerGridSim/`** フォルダ内に以下が生成されます：
- `PowerGridSim.exe` : ゲーム本体
- `config.json` : 難易度や設備データ（ユーザーがメモ帳等で自由に編集可能）
- `scenario.json` : イベントシナリオ（ユーザーが自由に編集可能）
- `assets/` : フォント等のアセット
- `README.md` : 説明書

> **配布方法**: `dist/PowerGridSim` フォルダごとZIP等に圧縮して配布すれば、相手のPCにPythonやPyxelがインストールされていなくてもそのまま遊んでもらえます。

## 3. ゲームルール & システム概要

### 🎯 主な目標
1. **周波数を 60.00 Hz に保つ**：
   - **供給（発電） > 需要** のとき、周波数が **上昇** します。
   - **供給（発電） < 需要** のとき、周波数が **低下** します。
   - 許容範囲（例: 60.00 ± 0.50 Hz）を一定時間（例: 5秒間）以上逸脱し続けると、**系統崩壊（BLACKOUT）** が発生しゲームオーバーとなります。
   - 危険域に入ると、画面の警報ランプ・メーターが赤く点滅し、ピピピッと警告音が鳴り響きます。
2. **電力を販売してスコア（累計売電額）と資金を獲得する**：
   - 需要家（民家・工場）に送電している間、`供給電力量 × 単価` で売電収入が入ります。
   - 基準単価は **30円/kWh** ですが、市場イベントによって係数が変動します。
3. **獲得した資金で発電所を増設する**：
   - 街は時間経過とともに発展し、新しい住宅街や工場が自動接続されて負荷が増えていきます。
   - 蓄えた資金で火力・水力・揚水発電所を増設して増大する需要に応えましょう。

## 3. 発電所 & 系統設備一覧

| 設備種別 | 特徴 | プレイヤーの操作 |
| :--- | :--- | :--- |
| **火力発電所** | 出力を広範囲に調整可能。追従速度（ランプ速度）のタイムラグがある。 | **出力調整スライダー**（ドラッグ）<br>`[-10 (Q)]`, `[-1 (S)]`, `[+1 (W)]`, `[+10 (E)]`<br>`[MIN (A)]`, `[MAX (D)]`<br>調整後、**`[指令送信 (Enter)]`** で確定 |
| **流れ込み式水力発電所** | 河川の流量に応じて安定発電するクリーンなベースロード。豊水イベントで発電量がUP。 | ベースロード（安定自動出力・操作不可） |
| **揚水発電所** | 上部ダムに水を貯めておく蓄電プラント。**高効率・超高速応答（定格70MW）**。 | `[停止 (A)]`, `[発電 (W)]`, `[揚水 (S)]` モード選択後、<br>**`[指令送信 (Enter)]`** で確定 |
| **中央変電所** | 発電所と街（全需要家）を結ぶ電力系統の要。<br>**受給オブジェクト毎に個別の接続・遮断を設定可能**。 | クリック / Tab選択後、`[系統開閉盤を開く (Space)]`<br>ダイアログで各設備を設定後、**`[指令送信 (Enter)]`** で確定 |
| **需要家（民家・工場）** | 時間経過や街の発展で負荷が増大。送電中に売電収益が発生。 | ステータス・負荷の閲覧のみ（※個別送電停止は不可。送受電制御は中央変電所の系統開閉盤で行います） |

### 💡 揚水発電を使ったハイスコア戦略
- **単価係数 < 1.0 のとき（電力余剰・休日・豊水など）**:
  - 需要が減って周波数が上昇傾向になります。
  - ここで揚水発電所を **`揚水 (PUMP)`** に切り替えて指令送信！
  - 系統から大電力を消費して周波数の急上昇を抑えつつ、安値の電気で上部ダムを満タンにチャージできます。
- **単価係数 > 1.0 のとき（電力不足・夕暮れ・寒波など）**:
  - 需要が跳ね上がり周波数が低下傾向になります。
  - ここで揚水発電所を **`発電 (GEN)`** に切り替えて指令送信！
  - 一気に大電力（定格70MW）を供給して周波数低下を防ぎつつ、高騰したプレミア単価で大量売電して莫大な収益を獲得できます。

## 4. 司令塔モード（時間停止と指令送信システム）

- **時間一時停止（何もないところを左クリック）**:
  - マップ上の空き地（何もない場所）を**左クリック**すると、ゲーム内シミュレーション時間をいつでも一時停止（ポーズ）できます。もう一度空き地を左クリック、または**右クリック / Spaceキー**で時間を再開できます。
- **オブジェクト選択中の時間停止**:
  - 発電所や需要家をクリック（または `Tab` キー）で選択している間も、**ゲーム内シミュレーション時間は一時停止**します。
  - 画面上部に `[⏸停止]` およびガイダンスバーが表示され、じっくり状況を分析して指令をセットできます。
- **指令送信と待機時間（クールダウン）**:
  - 指令を設定後、**`[指令送信 (Enter)]`** ボタンを押すか `Enter` キーを押すと指令が送信され、その設備に**指令応答待機時間（クールダウン）**が発生します。
  - 送信完了と同時に選択が解除され、ゲーム内時間が再び動き出します（画面上部は `[▶稼働]` に変化）。
- **選択解除・時間再開**:
  - 指令を変更せずに時間を再開したい場合、**マウス右クリック**、**空き地クリック**、または **`[閉じる (右)]`** ボタンで即座に時間再開できます。
- **メニューへの復帰**:
  - プレイ中・一時停止中・ゲームオーバー画面のいつでも **`ESC`** キーを押すと、ゲームを終了することなくタイトルメニュー（難易度選択画面）へスムーズに戻ることができます。
- **中央変電所 - 系統開閉盤（受給オブジェクトごとの接続・遮断制御）**:
  - 中央変電所を選択し、**`[系統開閉盤を開く (Space)]`** を押すと、全画面ダイアログ形式の **「系統開閉盤」** が開きます（開いている間、時間は一時停止します）。
  - **タブ切り替え**: **`供給側（発電所）`** と **`需要側（町・工場）`** のタブを切り替えて、増設された設備や発展した街の負荷をスクロールしながら個別確認できます。
  - **個別開閉器操作**: 各設備カードの `[ 接続 (ON) ]` / `[ 遮断 (OFF) ]` ボタンを押すことで、設備ごとに系統接続・切り離しを自由に設定できます。
  - **一括操作ボタン**: `[全接続]` / `[全切断]` により、一括操作も素早く実行できます。
  - **開閉後需給プレビュー**: ダイアログ下部には、開閉器操作を実行した場合の **予想供給MW / 予想需要MW / 需給差MW** がリアルタイムでシミュレーション表示され、周波数安定化に向けた最適な開閉判断が可能です。
  - **指令送信**: **`[ 指令送信・開閉操作を確定 (Enter) ]`** を押すと全設定が一括確定され、待機時間（クールダウン）を経てゲーム時間が再開します。
- **需要オブジェクト追加の事前予告システム**:
  - 街の自動発展により新しい需要家（新興住宅街やハイテク工場）が送電網に追加される **約12秒前** に、予告チャイムとともに画面上部にカウントダウン予告メッセージが表示されます。
  - 同時にマップ上の建設予定地にも点滅する「【建設予定地】」マーカーが現れ、どこにどの程度の負荷が接続されるかを事前に把握・準備できます。
- **メッセージ表示領域の1行固定化 & 履歴ログ画面（ゲームオーバー後も閲覧可能）**:
  - メッセージ表示領域は、発電所や需要家オブジェクトと絶対に重ならないよう、上部 HUD 直下の **1行固定バー（y=42〜55）** に最適化されています。
  - メッセージバーをクリック、または **`L`** キーを押すと、**ゲーム内時間が自動停止**し、モーダル形式の **「メッセージ履歴ログ」** 画面が開きます。
  - **ゲームオーバー（BLACKOUT）発生後も、画面内の `[ 履歴ログ確認 ]` ボタンまたは `L` キーで過去ログを確認可能**です。どのタイミングで何のイベントが起き、なぜ停電に至ったのかをじっくり振り返ることができます。
  - 過去に発生したイベント予告、イベント発生/終了、街の発展予告/接続、設備の着工/完成、ブラックアウト発生などを、**ゲーム内経過時間タイムスタンプ付き** で一覧確認・スクロールできます。
  - マウスホイールや上下キーで履歴をスクロールでき、右上の **`[閉じる X]`** ボタンや画面外クリック、右クリック、ESCキーで瞬時にゲームへ復帰できます。
- **イベント発生中メッセージのリアルタイム表示**:
  - シナリオイベント発生中は、イベント期間全体にわたって「【イベント発生中: ◯◯】状況説明 (残り秒数)」がヘッダー直下に明瞭に表示され続けます。
- **ゲームオーバー（BLACKOUT）後の再挑戦**:
  - **右クリック** または **`R`** キーで素早くリトライ可能。タイトルに戻るには **`ESC`** または **`Q`** キー。

## 5. UIと監視機能

- **上部 HUD**:
  - 経過時間、所持資金、累計売電スコア、現在単価（基準30円 × 係数）、需給サマリー（供給MW / 需要MW / 需給差）。
  - **周波数メーター**: 許容安全ゾーン（緑帯）、中央60Hzライン、現在の指針、現在周波数数値。
  - **周波数異常アラート演出**:
    - 周波数が許容範囲を逸脱すると、**周波数メーターの外枠が赤色に激しく点滅**します。
    - 同時に、**画面の周りの外枠（ボーダー）が赤色点滅**し、危険度が増す（系統停止が迫る）につれて点滅周期が高速化（かつ枠が太く変化）して危機感を強力に演出します。画面中央の視認性を邪魔することなく、クリアに警戒状態を把握できます。
- **中央マップ**:
  - 送電網のトポロジーと各発電所・需要家の稼働状態。
  - **潮流アニメーション**: 電線に流れる電力（MW）の向きと速さに応じたパルス粒子が流れます。過負荷に近づくと電線の色が橙〜赤に変化します。
  - **潮流ツールチップ**: マウスカーソルを電線の上に合わせると、`潮流: XX.X MW / 容量: XX MW` をリアルタイム監視できます。
- **下部コントロールパネル**:
  - 選択中のオブジェクトの詳細ステータス・操作ボタン。
  - 設備新設ボタン（火力増設 / 水力増設 / 揚水増設）。

## 6. シナリオ・設定のカスタマイズ（外部モデル化）

イベントや難易度は JSON ファイルで簡単に編集・追加できます。

### `config.json`
難易度別の周波数許容範囲や猶予時間、発電設備のパラメータを設定できます。
```json
"difficulties": {
  "easy": {
    "name": "初級 (Easy)",
    "freq_tolerance_hz": 0.8,
    "max_violation_duration_sec": 8.0,
    "initial_money_bonus": 50000
  },
  "normal": {
    "name": "中級 (Normal)",
    "freq_tolerance_hz": 0.5,
    "max_violation_duration_sec": 5.0,
    "initial_money_bonus": 0
  },
  "hard": {
    "name": "上級 (Hard)",
    "freq_tolerance_hz": 0.3,
    "max_violation_duration_sec": 3.0,
    "initial_money_bonus": -30000
  }
}
```

### `scenario.json`
時間経過で発生するイベント、事前予告の秒数、予告メッセージ、単価や負荷の倍率を設定できます。
```json
{
  "trigger_time_sec": 180,
  "notice_time_sec": 15,
  "duration_sec": 45,
  "name": "突発的寒波の襲来",
  "notice_msg": "【予告】急激な寒波が接近中！暖房需要爆発で電力ひっ迫、単価が超高騰する見込みです！",
  "active_msg": "【イベント発生】大寒波襲来！電力不足警報発令中！揚水発電を全開にして高値売電を狙え！",
  "price_multiplier": 2.2,
  "load_multiplier": 1.6,
  "hydro_multiplier": 0.8
}
```
新しいイベントを追加したい場合は、上記のオブジェクトを配列内に追加するだけで即座にゲーム内に反映されます。
