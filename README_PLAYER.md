# 電力運用シミュレータ (Electric Power Company Simulator)

Pyxel（レトロゲームエンジン）で開発された2D電力需給・周波数制御シミュレーションゲームです。
プレイヤーは中央給電指令所となり、町の送配電網を俯瞰しながら発電所出力と送電をコントロールし、**定格周波数 60.00 Hz** を維持しつつハイスコア（累計売電収入）を目指します。

---

## 1. 起動方法

### ゲームの起動
本フォルダ内の **`PowerGridSim.exe`** をダブルクリックして起動してください。
※ Python や追加ライブラリのインストールは一切不要です。Windows PC でそのまま遊ぶことができます。

---

## 2. ゲームルール & 主な目標

### 🎮 ゲームモード（ストーリーモード & フリーモード）
タイトル画面から選べるゲームモード：
1. **初級（ストーリーモード 全5話）**：
   - 新任の電力司令塔として、5つのステージを通して段階的に電力制御・設備投資をマスターしていくストーリー付きモードです。
   - **ステージ開始前画面**で、サブタイトル・あらすじ・発生するイベントの予告・クリア条件を確認し、`[運用開始]` を押すとスタート！
   - 条件を達成するとステージクリアとなり、司令官からの表彰メッセージとともに次のステージへ進みます。
   - **全5ステージの構成**：
     - **第1話：新任司令塔、着任！**（需給の基本と火力出力調整 / クリア目標: 所持金1,800万円）
     - **第2話：谷と山の水力パワー**（余剰電力の揚水充電とピーク発電 / クリア目標: 所持金2,000万円）
     - **第3話：町の発展と新たな力**（需要急増に備える発電所新設 / クリア目標: 発電所4基以上保有 & 所持金2,000万円）
     - **第4話：激動の気象急変**（豪雨と寒波！揚水2拠点大作戦 / クリア目標: 揚水2か所以上保有 & 所持金2,500万円）
     - **最終話：メガシティ・グリッドの夜明け**（大都市の繁栄と3000万円の偉業 / クリア目標: 所持金3,000万円達成！）
2. **中級・上級（フリーモード）**：
   - 時間無制限のエンドレス運用モード。よりシビアな周波数許容範囲と操作待機時間の中で、ハイスコアと連続稼働時間の限界に挑戦します。

### 🎯 主な目標
1. **周波数を 60.00 Hz に保つ**：
   - **供給（発電） > 需要** のとき、周波数が **上昇** します。
   - **供給（発電） < 需要** のとき、周波数が **低下** します。
   - 許容範囲（例: 60.00 ± 0.50 Hz）を一定時間（例: 5秒間）以上逸脱し続けると、**系統崩壊（BLACKOUT）** が発生しゲームオーバーとなります。
   - 周波数異常が発生すると、メーターおよび画面の外枠がピカピカと赤色点滅して警戒を知らせます。
2. **電力を販売してスコア（累計売電額）と資金を獲得する**：
   - 需要家（民家・工場）に送電している間、`供給電力量 × 単価` で売電収入が入ります。
   - 基準単価は **30円/kWh** ですが、市場イベントによって係数が変動します。
3. **獲得した資金で発電所を増設する**：
   - 街は時間経過とともに発展し、新しい住宅街や工場が自動接続されて負荷が増えていきます。
   - 蓄えた資金で火力・水力・揚水発電所を増設して増大する需要に応えましょう。

## 3. 発電所 & 系統設備一覧

| 設備種別 | 特徴 | プレイヤーの操作 |
| :--- | :--- | :--- |
| **火力発電所** | 出力を広範囲に調整可能。追従速度（ランプ速度）のタイムラグがある。 | **出力調整スライダー**（ドラッグ）<br>`[-10 (Q)]`, `[-1 (S)]`, `[+1 (W)]`, `[+10 (E)]`<br>`[MIN (A)]`, `[MAX (D)]`<br>調整後、**`[指令送信 (Enter)]`** で確定 |
| **流れ込み式水力発電所** | 河川の流量に応じて安定発電するクリーンなベースロード。豊水イベントで発電量がUP。 | ベースロード（安定自動出力・操作不可） |
| **揚水発電所** | 上部ダムに水を貯めておく蓄電プラント。**高効率・超高速応答（定格70MW）**。 | `[停止 (A)]`, `[発電 (W)]`, `[揚水 (S)]` モード選択後、<br>**`[指令送信 (Enter)]`** で確定 |
| **中央変電所** | 発電所と街（全需要家）を結ぶ電力系統の要。<br>**受給オブジェクト毎に個別の接続・遮断を設定可能**。 | クリック / Tab選択後、`[系統開閉盤を開く (Space)]`<br>ダイアログで各設備を設定後、**`[指令送信 (Enter)]`** で確定 |
| **需要家（民家・工場）** | 時間経過や街の発展で負荷が増大。送電中に売電収益が発生。 | ステータス・負荷の閲覧のみ（※個別送電停止は不可。送受電制御は中央変電所の系統開閉盤で行います） |

### 💡 揚水発電を使ったハイスコア戦略
- **単価係数 < 1.0 のとき（電力余剰・休日・豊水など）**:
  - 需要が減って周波数が上昇傾向になります。
  - ここで揚水発電所を **`揚水 (PUMP)`** に切り替えて指令送信！
  - 系統から大電力を消費して周波数の急上昇を抑えつつ、安値の電気で上部ダムを満タンにチャージできます。
- **単価係数 > 1.0 のとき（電力不足・夕暮れ・寒波など）**:
  - 需要が跳ね上がり周波数が低下傾向になります。
  - ここで揚水発電所を **`発電 (GEN)`** に切り替えて指令送信！
  - 一気に大電力（定格70MW）を供給して周波数低下を防ぎつつ、高騰したプレミア単価で大量売電して莫大な収益を獲得できます。

## 4. 司令塔モード（時間停止と指令送信システム）

- **時間一時停止（何もないところを左クリック）**:
  - マップ上の空き地（何もない場所）を**左クリック**すると、ゲーム内シミュレーション時間をいつでも一時停止（ポーズ）できます。もう一度空き地を左クリック、または**右クリック / Spaceキー**で時間を再開できます。
- **オブジェクト選択中の時間停止**:
  - 発電所や変電所、需要家をクリック（または `Tab` キー）で選択している間も、**ゲーム内シミュレーション時間は一時停止**します。じっくり状況を分析して指令をセットできます。
- **指令送信と待機時間（クールダウン）**:
  - 指令を設定後、**`[指令送信 (Enter)]`** ボタンを押すか `Enter` キーを押すと指令が送信され、その設備に**指令応答待機時間（クールダウン）**が発生します。送信完了と同時に選択が解除され、ゲーム内時間が再び動き出します。
- **中央変電所 - 系統開閉盤（受給個別制御）**:
  - 中央変電所を選択し、**`[系統開閉盤を開く (Space)]`** を押すと、専用ダイアログが開き、供給側（発電所）と需要側（町・工場）の各設備をタブ切り替え・スクロールしながら個別に接続・切断できます。
  - 開閉後予想需給（総発電 / 総需要 / 需給差）をプレビュー確認しながら、**`[ 指令送信 (Enter) ]`** で一括確定できます。
- **メッセージ表示領域 & 履歴ログ画面（ゲームオーバー後も閲覧可能）**:
  - 画面上部のメッセージバーをクリック、または **`L`** キーを押すと、時間が一時停止し、過去の全通報・指令・イベント履歴ログをスクロールして確認できます。
  - **ゲームオーバー（BLACKOUT）発生後も `[ 履歴ログ確認 ]` ボタンまたは `L` キーで過去ログを確認可能**です。
- **ゲームオーバー（BLACKOUT）後の再挑戦**:
  - **右クリック** または **`R`** キーで素早くリトライ可能。タイトルに戻るには **`ESC`** または **`Q`** キー。
- **メニューへの復帰**:
  - いつでも **`ESC`** キーを押すとタイトルメニューに戻ることができます。

## 5. 設定のカスタマイズ（外部ファイル編集）

本ゲームは、ゲームフォルダ内の JSON ファイルをメモ帳等で編集して自由にバランスをカスタマイズできます。

- **`config.json`**:
  - 初級・中級・上級の周波数許容範囲（`freq_tolerance_hz`）や許容時間、初期資金
  - 各発電所の建設コスト、建設所要時間、最大出力、追従速度（ランプ速度）など
- **`scenario.json`**:
  - ゲーム中に発生するイベントシナリオ（市場高騰、渇水、豊水、猛暑、寒波など）の発生タイミングや持続時間
